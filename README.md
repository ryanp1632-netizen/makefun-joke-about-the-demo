A tiny Node 22 program that writes one one-line joke about demoing beside an AI coding agent to `/output/entry.txt`, for the [make.fun "The joke about the demo" bounty](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
